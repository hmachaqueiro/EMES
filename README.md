# EMES - Prototipo de plataforma digital integrada

Este projeto implementa um protótipo funcional da plataforma digital da EMES, com base nos requisitos do caderno de encargos e anexos funcionais.

## Funcionalidades incluídas

- Homepage com mapa e indicadores de disponibilidade
- Fluxo de estacionamento com filtros e visualização de detalhes
- Perfis de utilizador: residente, trabalhador e visitante
- Pedido de dístico com validação de formulário
- Gestão de veículos e serviços online
- Pagamento e extensão de estacionamento
- Atualizações, notícias e apoio ao utilizador
- Backoffice com gestão operacional e relatórios
- Vista de aplicação mobile
- Login simulado para área do utilizador

## Como executar

1. Aceda à pasta do projeto.
2. Execute:
   ```bash
   python -m http.server 8000
   ```
3. Abra a página em:
   ```text
   http://localhost:8000
   ```

## Observações

- A solução é um protótipo front-end funcional em JavaScript puro.
- Os dados são mantidos em memória na aplicação.
- Foi concebida para demonstrar os fluxos principais do sistema para validação de requisitos.
